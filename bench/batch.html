🔬 Phase C.1 — Text-only OCR Comparison

เลือกภาพ Discord ใบเดียว แล้วเปรียบเทียบ Tesseract กับ OpenThai 2.1 ONNX หลายบรรทัด โดยโหลดโมเดล OpenThai ครั้งเดียว โหมด 12 บรรทัดจะข้ามหัวข้อความและ Reply ที่ตรวจพบแบบระมัดระวัง ระบบไฮไลต์ข้อความที่ต่างกัน แต่ไม่ได้ตัดสินว่าตัวไหนถูก จนกว่าจะกรอกข้อความเฉลย

1. เลือกภาพและเริ่มทดลอง

พร้อมทดลอง · ไม่มีการอัปโหลดภาพหรือข้อความไปยังบริการ OCR

ภาพและข้อความอยู่ในหน่วยความจำเบราว์เซอร์ ไม่บันทึกลง localStorage และไม่ส่งเข้า GitHub/CDN มีการดาวน์โหลดโมเดลและ JavaScript จาก CDN/Hugging Face เท่านั้น การรันหลายบรรทัดอาจใช้เวลาหรือหน่วยความจำมากบนมือถือ

2. สรุปผลเบื้องต้น

บรรทัดที่อ่านเหมือนกัน ไม่ได้แปลว่าอ่านถูก

ช่องเฉลยควรใส่เฉพาะตัวอักษรที่ปรากฏจริงในกรอบที่ส่งเข้า OCR อย่าใส่คำอธิบายแทนภาพ เช่น (โปรไฟล์) หรือ (อิโมจิ) มิฉะนั้น CER จะคลาดเคลื่อน โหมดกรองอาจลบอีโมจิที่อยู่ในเนื้อหาจริงด้วย ใช้เพื่อทดสอบเท่านั้น

ปุ่มนี้คัดลอกข้อความแชทจริง โปรดระวังเมื่อนำไปแชร์ ส่วนปุ่มสรุปเทคนิคด้านบนไม่รวมเนื้อหาแชท

ขอบเขตของการทดลอง

ตัวตรวจจับตำแหน่งบรรทัดยังใช้ Tesseract.js; OpenThai ใช้เพียงโมเดล rec.onnx + พจนานุกรม และ ONNX Runtime Web ผ่าน WASM ไม่ใช่ระบบ OpenThai เต็มที่มี det/rec2 และการแก้ภาษาไทยครบถ้วน ผลเปรียบเทียบนี้ยังไม่ใช่ความแม่นของ ChatLens ทั้งห้องแชท
